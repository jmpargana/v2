g8 Bytecode Instruction Set

Reference · Stack-based VM · v0.1 (arithmetic only)

Execution Model

g8 uses a stack machine. There are no named registers. Every instruction either pushes a value onto the stack or pops values, computes, and pushes the result. After a program finishes, the result is the single value remaining on the stack.

Instruction Format

Each instruction is one byte (the opcode), optionally followed by operand bytes. Operands are encoded as indices into a constant pool — an array of literal values attached to the bytecode program.

Opcodes

Opcode Byte Operands Stack effect Description
OpPush 0x00 1 byte (constant pool index) [] → [value] Push constants[operand] onto the stack.
OpAdd 0x01 none [a, b] → [a+b] Pop two values, push their sum.
OpMul 0x02 none [a, b] → [a×b] Pop two values, push their product.

Constant Pool

The constant pool is an []int array. When the compiler encounters a literal integer in the AST, it appends the value to the pool and emits an OpPush instruction with the pool index as the operand.

Compilation Rule

The compiler performs a post-order traversal of the AST: 

compile(node):
  if node is a leaf (Value != nil):
    idx = addConstant(node.Value)
    emit(OpPush, idx)
  else:
    compile(node.Left)
    compile(node.Right)
    emit(opFor(node.Op))  // OpAdd or OpMul

Example

Source: 30 + (20 * 40)

Constants: [30, 20, 40]

Bytecode:
  OpPush 0    // push 30
  OpPush 1    // push 20
  OpPush 2    // push 40
  OpMul       // 20 * 40 = 800
  OpAdd       // 30 + 800 = 830

Go Representation

type OpCode byte

const (
    OpPush OpCode = iota
    OpAdd
    OpMul
)

type Program struct {
    Code      []byte
    Constants []int
}

VM Execution

The VM is a fetch-decode-execute loop with three pieces of state: an instruction pointer (ip), a value stack, and the program. 

type VM struct {
    ip    int
    stack []int
}

func Run(program *Program) int {
    vm := &VM{}
    for vm.ip < len(program.Code) {
        op := OpCode(program.Code[vm.ip])
        vm.ip++
        switch op {
        case OpPush:
            idx := program.Code[vm.ip]
            vm.ip++
            vm.push(program.Constants[idx])
        case OpAdd:
            b, a := vm.pop(), vm.pop()
            vm.push(a + b)
        case OpMul:
            b, a := vm.pop(), vm.pop()
            vm.push(a * b)
        }
    }
    return vm.pop()
}
