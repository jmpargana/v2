# Mission: Bytecode Compilation for a V8 Isolate

## Why
Build a language that compiles to bytecode and runs inside a V8 isolate. The immediate goal is to understand the full pipeline from source code to execution — lexing, parsing, bytecode emission, and virtual machine execution — starting with a minimal arithmetic grammar and growing toward a language rich enough for V8.

## Success looks like
- Can explain what bytecode is and why it exists (vs. tree-walking or native code)
- Can compile an AST into a flat bytecode instruction sequence
- Can execute that bytecode on a simple stack-based VM written in Go
- Understands V8's register-based Ignition bytecode and how it differs from a stack machine
- Can target a V8 isolate with generated bytecode

## Constraints
- Already has a working lexer, parser, and AST for `a + (b * c)` style expressions (Go)
- Wants to build incrementally — start with the simplest possible bytecode, then grow
- Working in Go

## Out of scope
- JIT compilation (for now)
- Garbage collection
- Full JavaScript semantics
